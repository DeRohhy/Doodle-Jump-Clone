# Doodle Jump Clone 🚀

A simple Doodle Jump clone built with **C++** and **SFML 3.1.0**.

## Features
- Endless procedural platform generation
- Score tracking with increasing difficulty
- Enemies and hazards that spawn as you climb
- Background music and sound effects
- Shooting mechanic

## Controls
| Input | Action |
| --- | --- |
| `←` / `→` | Move left / right |
| `LMB` | Shoot |

## Requirements
- C++20 or newer compiler
- SFML 3.1.0
- `make`

## Build & Run
```bash
make && ./DoodleJumpClone.out
